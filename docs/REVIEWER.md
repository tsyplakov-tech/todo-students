# Независимая проверка через PostgreSQL

Согласуйте с владельцем готовой учебной БД отдельную роль `todo_reviewer` для преподавателя.
Ей нужны `CONNECT` к БД, `USAGE` на схему `todo` и `SELECT`, `INSERT`, `UPDATE`, `DELETE` на `todo.tasks`.
Права на прочие таблицы, историю миграций, DDL и создание ролей проверяющему не требуются.

Подключение преподавателя должно вести к той же БД, что DATABASE_URL приложения. Разрешите сеть только
нужному адресу или используйте ограниченный туннель. Не открывайте
5432 всему интернету. Для туннеля создайте отдельный системный доступ только к нужному порту; основной
SSH/Helios пароль не передавайте. При отсутствии таких прав выберите другую площадку или согласуйте доступ.

Лично сообщите преподавателю hostname/port/database/user todo_reviewer/password/TLS CA или параметры
согласованного туннеля, а также HTTPS-адрес и отдельный API-токен. Пароли Moodle/ИСУ не нужны.
Роль не имеет прав на прочие таблицы; учебная таблица целиком предназначена для проверки CRUD.

```bash
# REVIEW_DATABASE_URL — приватная строка с ролью todo_reviewer.
psql "$REVIEW_DATABASE_URL"
```

В psql задайте собственный Moodle-логин (тот же, что у сервера):

```sql
\set owner 'YOUR_MOODLE_LOGIN'
SELECT id, owner_login, title, done, run_id, created_at FROM todo.tasks;
-- Сверьте дело, созданное через интерфейс, с БД.
INSERT INTO todo.tasks(id, owner_login, title, done, run_id)
VALUES (gen_random_uuid(), :'owner', 'Добавлено преподавателем через SQL', false, 'review')
RETURNING id;
-- В интерфейсе выберите runId review и нажмите «Обновить».
UPDATE todo.tasks SET title='Изменено в SQL', done=true
WHERE owner_login=:'owner' AND run_id='review';
-- Обновите интерфейс: заголовок и флажок изменятся.
DELETE FROM todo.tasks WHERE owner_login=:'owner' AND run_id='review';
-- Обновите интерфейс: дела исчезнут. Также проверьте CRUD API → SQL.
```

В БД отсутствует автоматическая запись с личными данными. Создайте её вручную через приложение кнопкой
«Добавить итоговую работу» после настройки своего профиля; это соответствует требованию «через приложение».
